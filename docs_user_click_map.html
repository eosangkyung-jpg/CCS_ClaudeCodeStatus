실시간 사용량 캐릭터 위젯

상위 메뉴를 클릭하여 각 화면/영역별 조작 기능만 집중해서 확인하세요

🧍 캐릭터 본체 조작 기능

화면 위에 떠 있는 인물 밈(Meme) 플로팅 카드 위에서 발생하는 모든 동작

4개 인터랙션
  • HOVER 마우스 올리기 (Hover)
    • 머리 위에 상세 정보 말풍선 팝업 자동 슬라이드 노출
    • 커서를 캐릭터 밖으로 치우면 팝업 자동 사라짐
  • DRAG 마우스 좌클릭 후 드래그 (창 이동)
    • 모니터 화면 내 원하는 위치로 위젯 자유 이동
    • 마우스 손을 놓으면 현재 좌표 영구 저장 (다음번 앱 실행 시 해당 위치로 복원)
  • CLICK 우상단 작은 [ − ] 버튼 클릭
    • 위젯이 화면에서 사라지고 작업표시줄 트레이로 숨김
    • (앱이 완전 종료된 것이 아니며, 트레이 아이콘 클릭으로 언제든 다시 복원 가능)
  • CLICK-THROUGH 캐릭터 카드 밖 투명 빈 공간 클릭
    • 클릭 관통: 보이지 않는 투명 창에 막히지 않고, 뒷배경(브라우저, VS Code, 바탕화면 등)이 그대로 클릭됨

💬 말풍선 팝업 & 인라인 설정 패널

캐릭터에 마우스를 올렸을 때 나타나는 정보 카드와 [⚙️] 설정 버튼 내부 기능

3개 주요 기능 + 설정 패널
  • DISPLAY 상세 정보 표시 (눈으로 확인하는 정보)
    • 5시간 세션 사용량 게이지 바 & % 수치 & 리셋까지 남은 시간
    • 7일 주간 한도 게이지 바 & % 수치 & 리셋까지 남은 시간
    • 구간별 감정 상태 문구 (예: "토큰 넉넉해요", "멈춰! 지금 쏘면 끝장납니다")
    • 최근 데이터 갱신 시각 (예: 14:35:10)
  • CLICK 우상단 [ 🔄 ] 새로고침 버튼 클릭
    • 5분 대기 없이 즉시 Anthropic API 호출하여 최신 사용량 강제 동기화
  • CLICK 우상단 [ ⚙️ ] 설정 버튼 클릭
    • 팝업 하단에 [알림 상세 설정 패널]이 슬라이드로 열림 / 다시 누르면 닫힘
    ⚙️ 설정 패널 내부에서 선택 가능한 옵션들:
    💬 말풍선 알림 토글
    머리 위 만화풍 팝업 ON/OFF 마스터 스위치
    🔔 Windows 알림 토글
    우측 하단 네이티브 토스트 ON/OFF 마스터 스위치
    ⚡ 원클릭 프리셋 버튼
    • [모든 구간] : 8개 구간 전체 켬
    • [위험 구간만(80%+)] : 80% 이상만 켬
    • [모두 끄기] : 알림 완전 해제
    📊 8개 구간 매트릭스 표
    여유/안정/고민/기도/멈춰/95%/100%/리셋 구간별 말풍선·토스트 개별 체크박스 커스텀

🖥️ 작업표시줄 시스템 트레이 조작 기능

Windows 우측 하단 시계 옆 트레이 아이콘 좌클릭 및 우클릭 시 실행되는 기능

좌클릭 + 5개 우클릭 메뉴
  • LEFT CLICK 아이콘 좌클릭 (단일 클릭)
    • 숨겨져 있던 캐릭터 위젯을 화면에 즉시 다시 표시 (Show Window)
  • RIGHT CLICK 아이콘 우클릭 (컨텍스트 메뉴 열기)
    • [위젯 보이기 / 숨기기] 토글
    • [지금 새로고침] (즉시 API 동기화)
    🔔 [알림 방식 설정] 서브메뉴:
    ☑ 캐릭터 머리 위 말풍선 알림 (체크 토글)
    ☑ Windows 토스트 알림 (체크 토글)
    🧪 [상태 시뮬레이션] 서브메뉴 (원클릭 표정/알림 테스트):
    • 15% 여유 (초롱초롱)
    • 45% 안정 (턱 괴기)
    • 70% 고민 (웅크림)
    • 85% 기도 (비버 기도)
    • 92% 멈춰! (손바닥 스톱)
    • 97% 멘붕 (농구공 + 흔들림)
    • 100% 한도 소진 (흑백 + 타이머)
    • 리셋 완료 (거대한 손가락)
    • ↳ [종료 (Quit)] 클릭 시: 앱 프로세스 완전 종료 (앱을 완전히 끌 수 있는 유일한 통로)
